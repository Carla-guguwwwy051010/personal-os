# Personal OS 🐰

AI 驱动的个人成长操作系统 —— 帮助多线发展的成长型个人，把学习、工作、创造、生活统一到一个可持续记录的底座里。

单文件 Web 应用，无需构建、无需后端，打开即用。所有数据保存在浏览器 LocalStorage。

## ✨ 功能模块

| 模块 | 说明 |
|------|------|
| **首页 Dashboard** | 今日状态总览，联动日记复盘的心情/能量/关键词/总结 |
| **家教兼职** | 学生管理系统：学生信息 / 历史课程记录 / 未来课程安排，三 Tab 结构 |
| **创造中心** | 项目管理：项目介绍、推进记录、时间投入统计、阶段流转 |
| **日记复盘** | 每日状态记录：关键词、心情、能量条、心情笔记，按日期归档 |
| **体验放松** | 计划 → 完成 → 记录 → 复盘的完整体验管理闭环 |
| **PM 工作台** | 产品项目管理与资产库（PRD / 周报 / 竞品 / 机制） |
| **Learning** | 备考中心与 AI 学习追踪 |
| **Health Hub** | 健康与运动记录 |

## 🚀 快速开始

无需安装任何依赖，两种方式任选其一：

```bash
# 方式一：直接打开
# 双击 index.html，用浏览器打开即可

# 方式二：本地静态服务器（推荐，避免部分浏览器的 file:// 限制）
python -m http.server 8848
# 然后访问 http://localhost:8848/index.html
```

## 🛠 技术栈

- **单文件架构**：全部 HTML / CSS / JavaScript 内联于 `index.html`
- **React**（通过 CDN 引入，无构建步骤）
- **Tailwind CSS**（CDN）
- **Hash 路由**：`#/dashboard`、`#/tutoring`、`#/creation` 等
- **数据持久化**：浏览器 LocalStorage
- **国际化**：内置中文 / English 双语切换

## 💾 数据说明

- 所有数据保存在浏览器本地（LocalStorage），不上传任何服务器。
- 清除浏览器数据会重置为初始示例数据。
- 支持在设置页导出 / 导入数据。
